1. HTML 是什麼

HTML(HyperText Markup Language)是網頁的結構與內容,用「標籤(tag)」告訴瀏覽器每段內容的意義。

  • HTML:結構(骨架)
  • CSS:樣式(外觀)
  • JavaScript:行為(互動)

標籤通常成對出現:<p>內容</p>;屬性寫在開始標籤內:<a href="...">。

2. 基本結構

<!DOCTYPE html>
<html lang="zh-Hant">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>頁面標題</title>
</head>
<body>
  <!-- 使用者看得到的內容 -->
</body>
</html>
  • <!DOCTYPE html>:宣告使用 HTML5。
  • <head>:給瀏覽器看的資訊(編碼、標題、CSS)。
  • <body>:實際顯示在畫面上的內容。
  • charset="UTF-8" 沒設定,中文容易變亂碼。

3. 文字與標題

標籤用途
<h1> ~ <h6>標題,h1 最大;一頁通常只有一個 h1
<p>段落
<strong> / <em>強調(粗體 / 斜體),有語意
<br>換行(不需結束標籤)
<hr>水平分隔線

HTML 會把多個空白與換行合併成一個空白,要換行請用 <br> 或分成不同段落。

4. 連結與圖片

<a href="https://example.com" target="_blank" rel="noopener">外部連結</a>
<a href="#intro">頁內跳轉</a>
<img src="photo.jpg" alt="圖片說明" width="300">
  • href:連結目標;target="_blank" 開新分頁,建議搭配 rel="noopener"。
  • alt:圖片替代文字,圖片載入失敗與螢幕閱讀器都會用到,務必填寫。
  • 路徑:相對路徑(./img/a.png)與絕對路徑(https://...)。

5. 清單與表格

<ul><li>無序清單</li></ul>
<ol><li>有序清單</li></ol>

<table>
  <thead><tr><th>日期</th><th>金額</th></tr></thead>
  <tbody><tr><td>10/05</td><td>120</td></tr></tbody>
</table>

表格結構:table → thead / tbody → tr(列)→ th / td(儲存格)。合併儲存格用 colspan、rowspan。表格用來呈現資料,不要拿來排版。

6. 表單

<form action="/submit" method="post">
  <label for="email">Email</label>
  <input type="email" id="email" name="email" required>

  <label for="pwd">密碼</label>
  <input type="password" id="pwd" name="pwd" minlength="6" required>

  <select name="category">
    <option value="food">飲食</option>
    <option value="traffic">交通</option>
  </select>

  <textarea name="note" rows="3"></textarea>
  <button type="submit">送出</button>
</form>
  • label for 對應 input id,點文字也能聚焦輸入框。
  • 常用 type:text、email、password、number、date、checkbox、radio。
  • name 是送到後端的欄位名稱;required、minlength 提供基本驗證。
  • method:GET 資料放網址;POST 資料放在請求內容。

7. 語意化標籤

用有意義的標籤取代滿滿的 <div>,有利於 SEO、無障礙與維護。

<header>  頁首、Logo、導覽
<nav>     導覽列
<main>    主要內容(一頁一個)
<section> 主題區塊
<article> 獨立文章
<aside>   側邊欄
<footer>  頁尾

8. 區塊與行內元素

區塊(block)行內(inline)
排列獨佔一行,預設撐滿寬度不換行,寬度依內容
可設寬高可以不行
範例div、p、h1、ulspan、a、strong、img

<div> 是通用區塊容器,<span> 是通用行內容器;可用 CSS 的 display 改變。

9. 本週心得

  • 先用 HTML 寫好有意義的結構,再用 CSS 美化。
  • 善用瀏覽器開發者工具(F12)檢查元素、除錯。
  • 標籤要正確巢狀、記得關閉;縮排整齊比較好讀。
  • 圖片 alt、表單 label 這類細節,影響無障礙與使用體驗。
